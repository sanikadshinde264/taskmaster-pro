# 📝 TaskMaster Pro

> 🚀 A modern and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript** that helps users organize tasks efficiently through priority-based sorting, progress tracking, real-time statistics, and interactive productivity analytics.

## 🌟 Overview

**TaskMaster Pro** is a productivity-focused task management application designed to help users organize and track their daily tasks.

The application allows users to create tasks, assign priorities, set due dates, monitor completion progress, and analyze productivity through real-time statistics and an interactive analytics graph.

## 🎯 Problem Statement

Managing multiple tasks manually can make it difficult to identify priorities, track progress, and stay organized.

**TaskMaster Pro** provides a centralized and interactive solution for managing tasks, prioritizing important work, monitoring completion progress, and understanding productivity trends.

## ✨ Features

### ✅ Task Management

* ➕ Add new tasks with custom titles
* 📌 Assign priority levels:

  * 🔴 High
  * 🟡 Medium
  * 🟢 Low
* 📅 Set task due dates
* ☑️ Mark tasks as completed
* 🗑️ Delete tasks with smooth animations

### 📌 Smart Priority Sorting

Tasks are automatically organized based on:

1. ⏳ Pending tasks first
2. 🔴 High priority
3. 🟡 Medium priority
4. 🟢 Low priority

This keeps important and unfinished tasks easily visible.

### 📊 Real-Time Statistics

The dashboard provides real-time productivity information including:

* ✅ Completed task count
* ⏳ Pending task count
* 📈 Daily efficiency percentage

### 📈 Interactive Analytics Graph

The application uses the **HTML5 Canvas API** to visualize productivity trends.

Features include:

* 📊 Productivity trend visualization
* 📈 Progress history
* 🖱️ Interactive hover tooltips
* 🔄 Automatic updates based on user actions
* ✅ Completion progress tracking

### 🎯 Progress Tracking

A dynamic progress bar automatically updates according to the number of completed tasks.

This provides users with a quick visual representation of their overall task completion.

### 📅 Date Management

Each task stores important date information:

* 🕐 Creation date
* 📅 Due date

This helps users organize tasks and manage deadlines effectively.

### 🎨 Modern User Interface

The application includes:

* 🌑 Premium dark-themed task cards
* 🌈 Soft gradient background
* ✨ Smooth animations and transitions
* 🎨 Priority color indicators
* 📱 Responsive layout

### 📱 Responsive Design

TaskMaster Pro is optimized for:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

## 📊 Dataset

## ⚙️ Methodology

The project was developed using the following approach:

### 1️⃣ Task Creation

Users enter a task title, select a priority, and optionally provide a due date.

### 2️⃣ Task Storage

Task information is maintained dynamically using JavaScript data structures.

Each task contains information such as:

* Task title
* Priority
* Creation date
* Due date
* Completion status

### 3️⃣ Priority Sorting

Tasks are automatically sorted so that pending and high-priority tasks receive greater visibility.

### 4️⃣ Dynamic UI Rendering

JavaScript dynamically updates the task list whenever users:

* Add a task
* Complete a task
* Delete a task
* Change task-related information

### 5️⃣ Progress Calculation

The application calculates the percentage of completed tasks and updates the progress bar in real time.

### 6️⃣ Productivity Analytics

User actions and task completion data are used to update the productivity analytics graph.

### 7️⃣ Responsive Interface

CSS Flexbox, Grid, and responsive design techniques are used to provide a consistent experience across different screen sizes.
